# Photo Books (demo)

A small photo book storefront used to demo Factory workstreams. It is a made-up app, not production code.

- `src/` is the production app: a project list with pricing.
- `prototype/photo-book-editor/` is a designer's hand-off for the book editor. It is a working but messy prototype, kept as a read-only spec.
- `AGENTS.md` holds the engineering standards every change must meet.

```bash
npm ci
npm run dev
npm run check
```
